# Currency Converter

A simple Currency Converter application built using HTML, CSS, and JavaScript.

## Features

- Convert between different currencies using real-time exchange rates.
- Interactive and responsive UI.
- Fetches live exchange rates using an API.

## Technologies Used

- HTML
- CSS
- JavaScript
- API for exchange rates

## How to Use

1. Open the `index.html` file in your browser.
2. Select the currencies you want to convert from and to.
3. Enter the amount to be converted.
4. Click the convert button to get the exchange rate and converted amount.

## Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/currency-converter.git
   ```
2. Navigate to the project folder:
   ```bash
   cd currency-converter
   ```
3. Open `index.html` in your browser.

## API Integration

- The application fetches real-time exchange rates from an external API.
- Ensure you have an API key and include it in `api.js`.

## Files Overview

- `index.html` - Main UI for the converter.
- `styles.css` - Styling for the application.
- `script.js` - Handles DOM interactions and conversion logic.
- `api.js` - Fetches exchange rates from the API.
- `currency-code.js` - Contains currency codes and their respective country names.
